# Stimulus Tracker

**Open it:** https://keifp.github.io/stimulus-tracker/

A pipeline and permissions tracker for music theory assessment development. It follows each score or audio stimulus from sourcing through production (Sibelius engraving, Illustrator annotation, audio editing, alt text), internal and committee review, permissions clearance, and placement in the item bank. Built by Keith Pace, D.M.E., as a work sample for the administrative side of assessment development.

## Features

- **Three views:** a sortable table, a pipeline board by stage, and a permissions log for third-party stimuli.
- **Production checklist:** Score, SVG annotation, Audio, Alt text, and Item bank placement for every stimulus.
- **At-risk flags:** due within 14 days and not ready, permissions waiting more than 30 days, denied requests, and rights expiring within 90 days.
- **Summary dashboard:** totals, ready count, open permissions, and overall production progress.
- **Add, edit, filter, and export:** search and filter by stage, permissions, or risk; export to CSV for a permissions team or project plan.
- **Accessible:** keyboard operable, sortable headers announce their state, and status changes are announced to screen readers.

Data is stored in the browser (localStorage). The sample data is fictional.
